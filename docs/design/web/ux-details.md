1. 停止按钮与发送键合而为一。当session正在进行中且输入框为空时，按钮显示为停止；当session正在进行且输入框有内容时，按钮显示为发送；当session空闲时且输入框为空，发送按钮置灰。
2. 当个会话的聊天内容可能有很多，打开一个已存在的会话时，默认只通过网络加载最新的若干条消息，历史消息按通过手势下拉的方式加载。
3. 连续的多个工具调用操作可以默认合并展示，比如“读取3个文件、修改2个文件...等5个操作”。用户可以通过再次点击该条目展开查看每个具体操作。
4. 支持离线缓存一些内容，用户无网络打开App也能看到之前加载的会话。无需所有信息全部缓存，缓存一点点让用户打开网页App也能有基本的使用体验。我会使用移动端PWA将网页App安装到主屏幕，从而实现更接近原生App的使用体验。
5. 如果会话正在进行中，用户新发送的消息默认悬浮在输入框上方进入等待状态。Pending的消息应该提前发送到服务器，以便网页离线时也能在会话进入Idle状态后继续插入。Pending的消息同时展示“引导会话”、“撤回编辑”和“删除”三个按钮。引导会话按钮点击后，会立即暂停会话，并发送该用户消息进入新的交互轮次。
6. 已排队的pending消息，只有第一条才允许”引导会话”，排在后面的消息引导按钮置灰。
