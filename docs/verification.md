# 验证记录

## 0.1.3

- Go 全量测试、vet、Native 主程序构建及 18 项构建/发布工具测试通过。
- MyGo 离线交互与截图覆盖共享开关、停止/退出登录/重启确认、验证码弹窗、待验证地址、查看日志、480/640 px 宽度、最小窗口高度及长地址换行；保留已有图标。
- 启动回归确认每轮四项明细检查并行、账号不重复查询；待验证地址不能授权访问，失败、取消和迟到回调均不能恢复共享。
- 日志回归覆盖有界队列、轮转、并发退出刷盘、丢弃计数和写入失败提示；模拟非法 IPC 帧和事件会记录固定断开原因，不泄露消息内容或任意错误文本。
- 本轮未重启真实 Desktop、操作真实 Microsoft 登录或共享，也未在另一台电脑复现突然断连；尚不能确定该故障根因。离线截图不包含 Windows 自绘的系统窗口按钮。

- 本轮未重启用户正在运行的 Desktop，也未对真实会话执行压缩或新建测试；新版 shim 的真实双端联调、实体手机长按行为仍需验证。
